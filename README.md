# 🤖 Douman Panel Bot (دمان پنل بات)

### ربات فروش خودکار کانفیگ و اشتراک VPN، بازطراحی و بهینه‌سازی‌شده برای اجرا روی پنل پایتون سرورهای وردپرسی (Setup Python App)، هاست‌های اشتراکی و اتصال مستقیم به پیشخوان وردپرس (WP-Admin).

---

## ✨ ویژگی‌های برجسته نسخه بازسازی‌شده

- 🐍 **پشتیبانی کامل از Setup Python App (سی‌پنل / دایرکت‌ادمین):**
  - دارای ورودی رسمی `passenger_wsgi.py` جهت اجرای بدون قطعی روی Phusion Passenger
  - معماری مبتنی بر وب‌هوک (Webhook-driven) جهت سازگاری کامل با محدودیت‌های هاست‌های اشتراکی
  - مصرف بسیار پایین رم و پردازنده بدون نیاز به سرور مجازی (VPS)
- 🌐 **سازگاری کامل نسخه PHP با هاست‌های وردپرسی:**
  - حذف قفل نسخه PHP 8.5 و سازگاری با تمامی نسخه‌های استاندارد PHP (8.0, 8.1, 8.2, 8.3)
  - رفع خطای 403 / "Unauthorized access" در پشت کلودفلر (Cloudflare)، لایت‌اسپید و پروکسی معکوس وردپرس
  - سازگاری کامل فایل‌های `.htaccess` با ساختار ساب‌دامین و پوشه‌های وردپرس (`public_html/bot`)
  - نصب‌کننده سریع تحت وب ۱-کلیکه (`quick_install.php`)
- 🔌 **افزونه اختصاصی پیشخوان وردپرس (`wordpress-plugin`):**
  - افزودن منوی مدیریت به نوار کناری پیشخوان وردپرس (`/wp-admin`)
  - ثبت و حذف وب‌هوک تلگرام با یک کلیک از داخل وردپرس
  - مانیتورینگ سلامت ربات، مشاهده خطاهای تلگرام و تعداد درخواست‌های در صف
  - نمایش مستقیم پنل مدیریت تحت وب داخل پیشخوان
- 🧩 **اتصال مستقیم به معتبرترین پنل‌های مدیریت VPN:**
  - 🟢 **Marzban (مرزبان):** ساخت خودکار کاربر، تعیین حجم و انقضا، دریافت لینک ساب‌اسکریپشن
  - 🟢 **3X-UI (سنایی / علیرضا / فرانتس کافکا):** ورود با نشست، ایجاد کلاینت‌های Vless/Vmess، لینک ساب
  - 🟢 **Hiddify Manager (هیدیفای):** ایجاد کاربر از طریق REST API و لینک هوشمند
- 💳 **سیستم مالی و پرداخت:**
  - واریز کارت به کارت هوشمند با ارسال عکس فیش و دکمه‌های تایید/رد در تلگرام ادمین
  - درگاه آنلاین زرین‌پال و ارز دیجیتال
  - کیف پول و ثبت سوابق تراکنش‌ها

## ⚡ شروع سریع (Quick Start)

### ۱. اجرای پایتون در Setup Python App سی‌پنل:
1. در سی‌پنل به **Setup Python App** رفته و یک اپلیکیشن جدید بسازید (`passenger_wsgi.py`).
2. فایل‌ها را آپلود کرده و فایل `.env.example` را به `.env` تغییر نام دهید و توکن خود را در آن وارد کنید.
3. در صفحه Python App دستور `pip install -r requirements.txt` را اجرا کنید.
4. دستور زیر را برای ثبت وب‌هوک اجرا کنید:
   ```bash
   python set_webhook.py --set https://yourdomain.com/bot/webhook
   ```

### ۲. اجرای نسخه PHP در کنار وردپرس:
1. محتویات پوشه `php_engine/` را داخل پوشه‌ای مانند `public_html/bot` قرار دهید.
2. در مرورگر آدرس `https://yourdomain.com/bot/quick_install.php` را باز کنید.
3. مشخصات دیتابیس MySQL و توکن را وارد کرده و دکمه نصب را بزنید.

### ۳. نصب افزونه وردپرس:
پوشه `wordpress-plugin/doumanpanelbot-bridge` را در `wp-content/plugins/` هاست وردپرس کپی کرده و در پیشخوان وردپرس فعال نمایید.
