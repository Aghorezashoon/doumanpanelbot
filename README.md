## 🌟 چه تغییرات و قابلیت‌های جدیدی اضافه شده است؟

1. 🌐 **طراحی و پیاده‌سازی وب‌سایت و لندینگ پیج اختصاصی (`landing.php`):**
   - در نسخه اصلی میرزا بات، هیچ وب‌سایتی وجود نداشت و کاربر در صورت باز کردن دامنه با خطای `Unauthorized access` مواجه می‌شد!
   - در این نسخه، یک **وب‌سایت مدرن با UI فوق‌العاده زیبا و ریسپانسیو** اضافه شده است که به محض باز کردن دامنه نمایش داده می‌شود.
   - **امکانات وب‌سایت:**
     - 🌍 **بررسی زنده پینگ و وضعیت سرورها:** تست پینگ بلادرنگ لوکیشن‌های آلمان، فنلاند، هلند، فرانسه، ترکیه و آمریکا
     - 💎 **نمایش کارت‌های تعرفه و پلن‌ها:** با اتصال مستقیم به ربات تلگرام جهت خرید
     - 📱 **راهنمای تصویری اتصال:** تب‌های مجزا برای اندروید (v2rayNG/Hiddify)، آیفون (Streisand/V2Box)، ویندوز (v2rayN) و مک
     - ❓ **سوالات متداول (FAQ):** آکاردئون تعاملی به همراه پشتیبانی و کانال تلگرام
     - 🔗 **دسترسی سریع به وب‌اپلیکیشن (Mini App) و پنل مدیریت ادمین**

2. 🚀 **رفع باگ قفل نسخه PHP و ناسازگاری لینوکس:**
   - در نسخه اصلی شرط غیرواقعی `PHP >= 8.5.12` قرار داشت که فرآیند نصب را روی اوبونتو متوقف می‌کرد. در این نسخه حداقل نسخه به `8.1.0` و نسخه هدف به `8.3` (پایدارترین نسخه LTS) تغییر یافت.

3. 🛡 **پشتیبانی کامل از کلودفلر (Cloudflare) و پروکسی معکوس:**
   - توابع اعتبارسنجی آی‌پی تلگرام بازنویسی شدند تا آی‌پی‌های پروکسی، لودبالانسر و کلودفلر مانع ارسال آپدیت‌های وب‌هوک نشوند.

4. 📦 **نصب سریع و بدون وابستگی به دانلود خارجی:**
   - اسکریپت `install.sh` بازنویسی شد تا در صورت کلون شدن ریپازیتوری روی سرور، فایل‌ها را مستقیماً از سورس محلی کپی کند و درگیر قطعی اینترنت بین‌الملل سرور، محدودیت‌های Rate Limit گیت‌هاب یا پرایوت بودن ریپازیتوری نشود.

5. 🧩 **پشتیبانی از ۱۳ پنل مدیریت محبوب:**
   - 🟢 Marzban (مرزبان) | 🟢 Marzneshin (مرزنشین)
   - 🟢 3X-UI / Sanaei / Alireza (سنایی / علیرضا)
   - 🟢 Hiddify (هیدیفای) | 🟢 S-UI
   - 🟢 WGDashboard (وایرگارد) | 🟢 MikroTik (میکروتیک) | 🟢 IBSng

## 🚀 راهنمای نصب سریع روی سرور مجازی (Ubuntu VPS)

### پیش‌نیازها:
- یک سرور مجازی (VPS) خام با سیستم‌عامل **Ubuntu 22.04** یا **Ubuntu 24.04**
- یک دامنه یا ساب‌دامین که DNS آن (A Record) به آی‌پی سرور شما متصل شده باشد.
- توکن ربات تلگرام (از `@BotFather`) و آیدی عددی تلگرام ادمین (از `@userinfobot`).

---

### دستور نصب سریع تک‌خطی (روی سرور با دسترسی root):

```bash
curl -sSL https://raw.githubusercontent.com/Aghorezashoon/doumanpanelbot/main/install.sh -o install.sh && bash install.sh
```

یا از طریق کلون کردن گیت:
```bash
git clone https://github.com/Aghorezashoon/doumanpanelbot.git && cd doumanpanelbot && bash install.sh
```

پس از اجرای اسکریپت، منوی تعاملی زیر ظاهر می‌شود:
```
1) Install Mirza
2) Update Mirza
3) Remove Mirza
4) Migrate: Free -> Pro
5) Renew SSL certificate
6) Help & Parameters
7) Exit
```
گزینه **`1`** را انتخاب کنید و سپس:
1. دامنه سرور را وارد کنید (مثلاً: `vpn.example.com`).
2. نام کاربری و پسورد دیتابیس MySQL را به دلخواه تعیین کنید.
3. توکن ربات تلگرام را وارد کنید.
4. آیدی عددی ادمین را وارد کنید.

اسکریپت تمامی نیازمندی‌ها شامل **Apache، MySQL، PHP 8.3، Composer، گواهی رایگان SSL (Let's Encrypt) و کران‌جاب‌ها** را به صورت ۱۰۰٪ خودکار نصب و فعال‌سازی می‌کند.

## 🌐 نحوه کارکرد دامنه پس از نصب:

| آدرس | عملکرد |
|---|---|
| `https://yourdomain.com/` | **وب‌سایت و لندینگ پیج حرفه‌ای دمان پنل** (وضعیت سرورها، پینگ، تعرفه‌ها، آموزش‌ها) |
| `https://yourdomain.com/index.php` | اندپوینت دریافت وب‌هوک‌های تلگرام (Telegram Webhook) |
| `https://yourdomain.com/admin.php` | پنل مدیریت تحت وب ادمین برای مدیریت مالی و کاربران |
| `https://yourdomain.com/app/` | وب‌اپلیکیشن تلگرام (Telegram Mini App) |
| `https://yourdomain.com/sub/...` | سرویس تولید خودکار لینک‌های ساب‌اسکریپشن |

## 📁 ساختار پوشه‌های پروژه

```
doumanpanelbot/
├── install.sh             # اسکریپت جامع نصب خودکار تمام پکیج‌ها و تنظیم سرور
├── index.php              # روتر هوشمند: نمایش سایت در مرورگر + وب‌هوک در تلگرام
├── landing.php            # لندینگ پیج و وب‌سایت مدرن و فوق‌العاده با UI حرفه‌ای
├── admin.php              # پنل مدیریت وب ادمین
├── botapi.php             # توابع ارتباطی با API رسمی تلگرام
├── config.php             # فایل پیکربندی دیتابیس و توکن‌ها
├── function.php           # توابع عمومی، محاسبات حجم، انقضا و QR کد
├── table.php              # اسکریپت ساخت خودکار جداول پایگاه داده MySQL
├── keyboard.php           # کیبوردهای منوی ربات تلگرام
│
├── app/                   # فرانت‌اند وب‌اپلیکیشن تلگرام (Mini App)
├── panels/                # درایورهای اتصال به پنل‌های مرزبان، سنایی، هیدیفای و...
├── payment/               # درگاه‌های بانکی، کارت به کارت، زرین‌پال و ارز دیجیتال
├── cronbot/               # جاب‌های دوره‌ای بررسی انقضای سرویس‌ها و پشتیبان‌گیری
├── db/                    # تعاریف جداول و مایگریشن‌های دیتابیس
├── sub/                   # ماژول تولید لینک‌های ساب‌اسکریپشن (Sub)
│
├── extra/                 # ابزارهای جانبی (موتور پایتون سی‌پنل Setup Python App)
└── wordpress-plugin/      # افزونه اختصاصی جهت اتصال ربات به پیشخوان وردپرس (wp-admin)
```
